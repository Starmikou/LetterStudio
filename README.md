# Letter Studio

> 一个给 Blender 用的文字贴图生成器：把中文、英文、数学公式渲染成高清透明 PNG，再作为素材导入 .blend。

## 为什么做这个项目

Blender 自带的 Text 对象有几个限制：

- 不能排版数学公式
- 中文等非拉丁字符依赖系统字体，经常显示成方框
- 字号是按 world unit 定义的，要控制它在画面里占多少像素得自己换算

所以这个程序从 Blender 外部生成文字，以 PNG 贴图的形式导入场景。
好处是分辨率由渲染参数决定（跟最终画面无关，可以出得很高清），并且是纯贴图、不经 Blender 的字体系统，显示效果更接近 2D 图层。

**需要说明的是：它不能替代 Blender 的 Text 功能。**
Text 对象是矢量的、可编辑、能做逐字动画、能被光照影响；这里生成的是贴图，导入后就是一张图。
两者适合的场景不同，这一点请按需要选择。

## 功能

- 中文 / 英文 / 数字 / 混排，缺字形时自动换后备字体
- LaTeX 数学公式，整行用 `$...$` 包起来，例如 `$E=mc^2$`
- 按像素指定字号，程序换算成 Blender 的场景尺度
- 读取系统字体（当前环境识别到 82 个字体族），支持中文名搜索
- 导出到指定 `.blend`，物体落在世界原点，导出前自动备份
- 环境自检：检查 Blender / LaTeX / 字体 / Pillow 是否就绪

## 安装

### 方式一：下载打包版

1. 到 [Releases](../../releases) 下载 `LetterStudio-Windows.zip`
2. 解压到任意文件夹（不要直接在 zip 里运行 exe）
3. 双击 `LetterStudio.exe`

> 程序没有数字签名，Windows 可能提示"已保护你的电脑"，
> 点"更多信息" → "仍要运行"。

### 方式二：从源码运行

```bash
pip install pillow
python LetterStudio.py
```

或双击 `启动 Letter Studio.bat`（内部调用 `pythonw.exe`，无控制台窗口）。

## 使用

1. **字号**：填目标像素高度，默认 72。这个数值对应 1080p 画面中的像素高度
2. **字体**：默认 Arial。可点"查看系统字体…"预览选择，也可直接输入中文名搜索
3. **文字内容**：一行一条，公式整行用 `$...$` 包裹
   ```
   i
   中文 ABC 123
   $E=mc^2$
   $\int_0^1 x^2\,dx$
   ```
4. 点 **生成预览**
5. 点 **导出到 Blender 文件…**，选择目标 `.blend`
6. 在 Blender 中打开，文字位于世界原点 `(0,0,0)`

导出前会自动备份为 `原文件名.blend.before_letter_studio`。

### 多行文字

每一行都独立落在 `(0,0,0)`，程序不做自动排布。
需要在 Blender 中移动时，选中对应行的 `文字_XX_CTRL` 空物体拖动。

这样设计是因为不同项目的相机取景差异很大，固定行距容易把内容推出画面。

### 颜色

导入后为白色文字，便于叠在深色背景上。
如需改为黑色：选中物体 → 材质面板 → 将 `Emission` 颜色改为黑色。

## 常见问题

**Q：报错"没有安装 LaTeX"？**
A：你输入了 `$公式$`，但本机没有 LaTeX 编译器。点"环境自检"查看状态，按提示安装 MiKTeX 后重启程序。普通文字不需要 LaTeX。

**Q：中文显示为方框？**
A：当前字体没有对应字形。程序会自动改用微软雅黑 / 黑体 / 宋体。若系统中这些字体也没有，请安装一个中文字体（如[思源黑体](https://fonts.google.com/noto/specimen/Noto+Sans+SC)）。

**Q：找不到 Blender？**
A：点"浏览…"手动指定 `blender.exe`，程序会记住该路径。安装在非默认位置时首次可能需要手动指定。

**Q：导出的字太大或太小？**
A：字号是 1080p 画面中的像素高度。如果最终渲染是 4K，把字号乘以 2（例如 144）。

**Q：为什么一行只能整体是公式？**
A：LaTeX 不支持在公式中间混入中文。`mixed 混排 ABC` 这类内容请按普通文字书写。

**Q：能替代 Blender 的 Text 对象吗？**
A：不能。Text 对象是矢量、可编辑、可做逐字动画、受光照影响；本工具生成的是 PNG 贴图。
本工具针对的是"公式排版"和"固定分辨率下的清晰显示"，两类需求不同。

**Q：能商用吗？**
A：代码为 MIT 协议，可商用。字体版权归字体厂商所有，使用微软雅黑等商用字体发布作品前请自行确认授权。

## 实现说明

- 文字在 Blender 后台模式下渲染，4 倍超采样后缩放，边缘不会发虚（`letter_render.py`）
- LaTeX 走 `latex` + `dvisvgm` 输出 SVG，再由 Blender 导入为曲线（`latex_to_svg.py`）
- 字体列表通过 FreeType（Pillow）读取真实字重，缓存在 `_cache/`（`letter_fonts.py`）
- 导入时把 PNG 贴到平面，父级空物体置于原点，便于整体移动（`letter_import.py`）
