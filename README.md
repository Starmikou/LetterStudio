# Letter Studio

> 给 Blender 用的文字素材生成器 —— 把中文、英文、数学公式变成可以拖进任何场景的贴图素材。

做火柴人动画、科普视频、教学演示的时候，最烦的就是往画面里放文字：
Blender 自带的文字对象打不了中文，更排不了 LaTeX 公式；用截图又糊。

Letter Studio 就是解决这件事的：**输入一行字 → 生成透明 PNG + 一个能直接拖进 Blender 的资产物体**，
字号按 1080p 画面里的真实像素算好，放进场景就是你要的大小。

---

## 功能

- **中文 / 英文 / 数字 / 混排** —— 一行里中英文可以混着写，缺字形会自动换后备字体
- **LaTeX 数学公式** —— 整行用 `$...$` 包起来即可，`$E=mc^2$`、`$\int_0^1 x^2\,dx$`
- **按像素定字号** —— 填 `72` 就是 1080p 画面里 72 像素高的字，不用自己换算世界坐标
- **真实字体渲染** —— 读取系统字体（82 个字体族），不是用默认字体凑合
- **中文字体名可搜** —— 直接搜"宋体""雅黑""思源黑体"，不用记英文名
- **导出即用** —— 点一下写进你指定的 `.blend`，物体就在世界原点 `(0,0,0)`，导出前自动备份
- **环境自检** —— 一键检查缺什么依赖，缺哪项就给哪项的下载地址

## 安装

### 方式一：下载打包版（推荐，不用装 Python）

1. 到 [Releases](../../releases) 页面下载 `LetterStudio-Windows.zip`
2. 解压到任意文件夹（**不要直接双击 zip 里的 exe**，必须先解压）
3. 双击 `LetterStudio.exe`

> 第一次启动可能要等几秒，Windows 可能弹出"已保护你的电脑"——
> 点"更多信息" → "仍要运行"即可（程序没有数字签名，这是正常的）。

### 方式二：从源码运行

需要 Python 3.10+ 和 Pillow：

```bash
pip install pillow
python LetterStudio.py
```

或者双击 `启动 Letter Studio.bat`（会把 `pythonw.exe` 找出来，运行时不弹黑框）。

> 源码版只有约 40 KB，适合已经装了 Python 的人。
> 不想装 Python 就用方式一的打包版。

## 怎么选：打包版还是源码版

## 使用

1. **字号**：填你想要的像素高度，默认 72（1080p 画面里 72 像素）
2. **字体**：默认 Arial；点"查看系统字体…"可以预览并挑选，也可以直接输入中文名搜索
3. **文字内容**：一行一条。公式整行用 `$...$` 包起来
   ```
   i
   中文 ABC 123
   $E=mc^2$
   $\int_0^1 x^2\,dx$
   ```
4. 点 **生成预览**，看效果和提示
5. 点 **导出到 Blender 文件…**，选择你的 `.blend`
6. 用 Blender 打开，文字就在世界原点 `(0,0,0)`

导出前会自动备份成 `你的文件.blend.before_letter_studio`，不用担心写坏。

### 关于多行

每行都会**独立落在** `(0,0,0)`，不会自动排布。
你想让第二行往下挪，在 Blender 里选中它对应的 `文字_01_CTRL` 空物体往上/下拖即可。

这样做是因为每个人的相机取景都不一样，自动排布反而容易把字推出画面。

### 关于颜色

导入的文字是**白色**的，方便直接放在深色背景上用。
如果要改成黑色，在 Blender 里选中物体，进材质面板，把 `Emission` 颜色改成黑色即可。

## 常见问题

**Q：点生成预览报错"没有安装 LaTeX"？**
A：你写了 `$公式$`，但本机没有 LaTeX。点界面上"环境自检" → 打开 MiKTeX 下载页安装，装完重启程序。
只写普通文字不需要 LaTeX。

**Q：中文显示成方框？**
A：当前字体没有中文字形。程序会自动换成微软雅黑/黑体/宋体；如果连这些都没有，请装一个中文字体
（如[思源黑体](https://fonts.google.com/noto/specimen/Noto+Sans+SC)）。

**Q：找不到 Blender？**
A：点"浏览…"手动选 `blender.exe`。程序会在下次启动时记住这个路径。
非默认安装位置（比如装在 D 盘）第一次可能需要手动指定一次。

**Q：导出的字太小 / 太大？**
A：字号就是 1080p 画面里的像素高度。如果你最终渲染是 4K，把字号翻倍（144）即可。

**Q：一行为什么只能整个是公式？**
A：LaTeX 不支持在公式中间夹中文。`mixed 混排 ABC` 这种要当普通文字写；
`$E=mc^2$` 这种纯公式才走 LaTeX。

**Q：能商用吗？**
A：可以，MIT 协议。但字体版权归字体厂商，用商用字体（如微软雅黑）发布作品前请自行确认授权。

## 技术说明

- 文字渲染在 Blender 后台模式下完成（`letter_render.py`），按超采样 4 倍出图再缩放，边缘不糊
- LaTeX 走 `latex` + `dvisvgm` 输出 SVG，再由 Blender 导入成曲线（`latex_to_svg.py`）
- 字体列表用 FreeType（Pillow）读取真实字重，缓存到 `_cache/`（`letter_fonts.py`）
- 导入时把 PNG 贴到一个平面，父级空物体放在原点，方便整体拖动（`letter_import.py`）
